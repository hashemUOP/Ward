# Ward
<p align="center">
  <img src="https://github.com/user-attachments/assets/3c9a3ef0-21a3-47ab-9c15-86c4fcad3375" width="250" alt="Ward Logo">
</p>

Ward is a Mobile application developed using **Flutter** for the frontend, **Firebase** (Auth & DB), and **Django (REST)** for the backend, and an **AI model** for plant type and diseases detection.
